# GURSHARAN AI — Integrated Android Build

This is the Android-buildable foundation for the GURSHARAN AI Agent.

- Native Android shell with WebView UI
- Existing GURSHARAN AI interface packaged in app assets
- Microphone permission for voice interaction foundation
- Shared configuration and Master Agent source retained
- Codemagic workflow included at repository root

The current build is an installable UI/agent foundation. Production AI backend, speaker verification, secure owner authorization, real phone-call integration, messaging integrations, and signed release distribution require their respective services/credentials and native integrations.
